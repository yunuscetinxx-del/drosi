# دروسي — تطبيق Flutter

تطبيق جوال **متكافئ مع موقع دروسي** (Next.js). نفس الحساب ونفس البيانات على المنصتين عبر مزامنة فورية مع `Next.js API`.

## الميزات (مكافئة للموقع)

- تسجيل دخول / إنشاء حساب — **نفس الحساب على الموقع والهاتف**.
- عرض / إضافة / تعديل / حذف الدروس.
- **الصور:** التقاط من **الكاميرا** أو اختيار من **المعرض** (صورة أو عدة صور)، مع ضغط تلقائي.
  - تُخزَّن كـ Base64 وتظهر على الموقع فوراً بعد الحفظ.
  - **تحليل الصور بالذكاء الاصطناعي** (`/api/analyze-image`) مع تعليمات اختيارية.
  - تعليقات/ملاحظات على الصورة، وإضافة نتيجة التحليل إلى ملاحظات الدرس.
- **تحليل الدرس بالذكاء الاصطناعي** (`/api/analyze-lesson`): الصعوبة، الاكتمال، نقاط القوة، نصائح دراسية…
- **الخرائط الذهنية** بمحرر لمسي:
  - تحريك العُقد بالإصبع، تكبير/تصغير وتحريك اللوحة.
  - إضافة عقدة رئيسية أو فرع، تعديل النص واللون والملاحظة، حذف العقدة وفروعها.
- **صفحات Word:** إنشاء وتحرير محتوى نصّي لكل درس.
- شارة **مدير** إن كان الحساب admin.

> مهم: التطبيق يحافظ على كل حقول الدرس (بما فيها ما لا يعرضه) فلا يتلف بيانات الموقع عند الحفظ.

## العمل بدون إنترنت (Offline-first)

- الدروس تُخزَّن **محلياً على الهاتف** وتُعرض فوراً عند فتح التطبيق (حتى بدون إنترنت).
- يمكنك **العرض والإضافة والتعديل والحذف** دون اتصال — تُحفظ التغييرات محلياً وتُعلَّم كـ "بانتظار المزامنة".
- عند عودة الاتصال تتم **المزامنة تلقائياً** مع الموقع، أو يدوياً من زر السحابة في الأعلى.
- شريط علوي يوضّح الحالة: بدون اتصال / تغييرات معلّقة / خطأ مزامنة، وشارة بعدد التغييرات المعلّقة.
- **سياسة الدمج:** التعديلات المحلية المعلّقة تفوز؛ وبقية الدروس تُحسم بـ "آخر تعديل يفوز" (`updatedAt`) لالتقاط تعديلات الموقع. الحذف المحلي يُطبَّق على الخادم.
- الدخول متاح دون إنترنت طالما يوجد رمز جلسة محفوظ (لا يُحذف الرمز عند انقطاع الشبكة، فقط عند انتهاء الجلسة فعلياً 401).

> ملاحظة: تحليل الذكاء الاصطناعي (الصور/الدروس) يتطلب اتصالاً لأنه يمر عبر الخادم.

## المتطلبات

- Flutter SDK
- خادم الموقع يعمل: `npm run dev` من مجلد المشروع الرئيسي

## 1) تشغيل الخادم (الموقع)

```powershell
cd e:\procat\dars
npm run dev
```

للوصول من **هاتف حقيقي** على نفس Wi‑Fi، شغّل الخادم على كل الواجهات:

```powershell
npx next dev -H 0.0.0.0 -p 3000
```

ثم استخدم في التطبيق: `http://IP_جهازك:3000` (مثلاً `http://192.168.1.10:3000`).

## 2) تشغيل تطبيق Flutter

```powershell
cd e:\procat\dars\mobile
flutter pub get
flutter run
```

- **Windows:** العنوان الافتراضي `http://localhost:3000`
- **Android Emulator:** `http://10.0.2.2:3000`
- **هاتف Android/iOS:** عنوان IP جهاز التطوير من **إعدادات الخادم** في شاشة الدخول

## 3) تثبيت APK على الهاتف

```powershell
cd mobile
flutter build apk --release
```

الملف: `build/app/outputs/flutter-apk/app-release.apk` — انقله للهاتف وثبّته.

## الأذونات

- **Android:** الإنترنت + الكاميرا (مُعرَّفة في `AndroidManifest.xml`).
- **iOS:** أوصاف استخدام الكاميرا والمعرض في `Info.plist`.

## API المستخدم

| المسار | الوظيفة |
|--------|---------|
| `POST /api/auth/login` | دخول (+ `token` للموبايل) |
| `POST /api/auth/register` | تسجيل |
| `GET /api/auth/me` | المستخدم الحالي |
| `GET/PUT /api/lessons` | قراءة / حفظ الدروس (مع الصور والخرائط وصفحات Word) |
| `POST /api/analyze-image` | تحليل صورة بالذكاء الاصطناعي |
| `POST /api/analyze-lesson` | تحليل الدرس بالذكاء الاصطناعي |

المصادقة: `Authorization: Bearer <token>`

## بنية الكود

```
lib/
├─ models/        # Lesson, LessonImage, MindMap, WordPage (مطابقة لـ types/lesson.ts)
├─ services/      # api_client, auth, lessons, image_service, ai_service
├─ providers/     # AppState (إدارة الحالة)
├─ screens/       # الدخول، الرئيسية، تفاصيل الدرس، محرر الخريطة/الصورة/الصفحة
├─ tabs/          # تبويبات تفاصيل الدرس (تفاصيل/صور/خرائط/صفحات)
└─ widgets/       # عرض الصور، لوحة الخريطة الذهنية
```
